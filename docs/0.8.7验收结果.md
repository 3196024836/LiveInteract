## 已修复并实测
- **隔空掉血**：旧版把朝圣钟卫的 Attack Range / Escape Range 子级触发器向上解析成根物体的DamageHero，实测相距约6.99单位仍扣友军血。现在只接收碰撞体同物体的真实伤害组件。相同大型感应区夹具下，钟卫友军20血保持；新默认焦油螨在约15秒采样中25血保持，没有通过无敌屏蔽伤害。
- **真正承伤仍有效**：原作敌人身体攻击实际贴合焦油螨，确实扣血；提高该真实攻击伤害后，友军死亡。没有直接写受测友军血量。
- **索敌**：同一原作2D感应区，目标在二维区域内而不在三维Bounds内（精灵Z排序不同）。改为OverlapPoint后，焦油螨自然进入原作Fire状态并发射焦油弹，不再只在Idle/Aggro间切换。
- **瞄准/实际命中**：两种友军分别面对左、右静止原作敌人，不注入攻击、不指定攻击状态。焦油螨右侧目标1000→985、左侧1000→987；钟卫右侧1000→996、左侧1000→997。保留原作弹体与时序，矮目标按身体受击框中心瞄准；钟卫仅校准出手横向速度，垂直起速、重力与反弹保持。四组友军自身血量都稳定。
- **阵营保护**：两种远程友军分别验证玩家攻击不扣友军血，友军各玩家伤害旁路不扣主播血；保留玩家正常受伤的阳性对照。
- **跟随/外观**：机械小弟与新远程小弟在Tut_01→Tut_02→Tut_01两次实际场景切换后保留原对象并存活；焦油螨离屏后召回。游戏截图确认新友军本体绿边、敌军红边、召唤者名字仍可见。
- **配置**：仍17条，只改变远程小弟/远程小怪的对应单位和名称，另外15条与0.8.6包完全一致。配置、透明直播图、使用说明一起更新。
- **自动化**：222/222测试通过，包括新增5项抛射计算用例和更新后的默认配置映射用例。实机记录24项检查全部通过；正式Mod非QA重建。
