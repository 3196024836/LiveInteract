# 花花直播互动 0.8.2 · 实机测试说明

## 开始使用
1. 先退出旧版互动工具，避免两个版本争用同一个游戏连接。完整解压，运行 `直播互动工具箱.exe`，界面名称为“花花直播互动”。保留同目录的 `payload`、`profiles` 和第三方许可。
2. 缺少 .NET 或 WebView2 时，软件内部会下载、校验并准备组件，不需要打开网页手动安装。首次准备需要联网；失败会显示原因并允许重试。
3. 关闭游戏后点击“一键准备游戏”，安装本工具 Mod；不会强制结束游戏，不移除其他 Mod。随后正常通过 Steam 启动游戏。
4. 点击“使用内置方案”载入本次默认配置。已有规则会先备份，不覆盖你未选择替换的自定义配置；互动总开关由你控制。
5. 在内置直播窗口选择抖音，登录并填写本人直播间地址。确认直播连接和游戏连接后，再开启互动。

## 阵营和画面
- 友军召唤者名字为浅绿色，敌人为红色，细描边、无常驻背景框。
- 玩家与友军互不伤害；友军仍能被敌人击败。敌方召唤物正常敌对。
- 持续友军按跨场景跟随逻辑保留；精准召唤仍有5秒时限。紧急停止会清理本工具召唤物。
- 互动召唤的Boss不应触发结局CG、通关写入或全局死亡慢镜头。正常剧情Boss不被全局禁用。
- `直播图/直播互动说明-透明.png` 来自当前默认配置；改过规则后，可在“画面与设置”重新生成。

## 实机测试时怎么检查
先不开播，使用软件内“发送一次测试输入”，依次检查上述四条召唤、名字颜色、友军承伤和切场景跟随；然后连接自己的直播间，分别验证弹幕、点赞和四件礼物。
消息与队列可按来源、状态和昵称筛选；显示筛选不消费真实队列。未知回执先核对，不盲目重复执行；故障时导出脱敏诊断。

`0.8.2召唤验收.csv` 记录逐项验收的候选与检查项。它证明表列的召唤/阵营/承伤检查，不等于每个Boss所有战斗阶段、所有机器或直播平台上游消息送达率的保证。正式开播前，以自己的游戏版本、直播账号和实际规则完成一次预演。

## 更新与恢复
软件内部检查更新，替换前验证更新包；更新失败会尝试回滚。直播开启、游戏运行或队列尚未处理时，不会自动重启替换。游戏Mod在游戏关闭时通过“一键准备游戏”更新。
本包不包含游戏程序集、游戏资源、存档或登录态；只在本机读取你已安装的游戏资源。
