# 丝之歌 · 免费双小弟与付费召唤（0.5）

需要0.5程序及Mod。在“触发规则”点“读取默认助力配置”，选择同目录的JSON。旧规则先备份，新规则不会自动打开互动开关。本配置共16条启用规则，不保留旧版免费刷怪、免费复制或自动聊天回血。

## 随从、整活与清理

四种友军直接使用四个不同原生单位的预制体、模型、动画与攻击碰撞，再适配阵营、追敌和跟随；不是机械随从换皮。两种基础小弟倍率1，木蜂倍率4，狱卒蝇倍率8。转友方适配属于Mod行为，不是游戏官方自带友方形态。

友军显示召唤者昵称，跨场景保留，不自动计时离场；不是写入存档的永久获得。正常退出、卸载或紧急停止会清理。免费“清场/恢复”口令已从默认移除，避免免费弹幕随时清掉付费召唤；主播仍可在工具中紧急恢复。

变大/变小每次各自保留触发者与到期时间，不覆盖上一条；只改外观，不扩大碰撞体。默认实体上限0表示不限制，不等于无限性能承载；可由主播显式设置上限。

随机Boss每份礼物只生成1只，同一执行单位加载重试不重新抽签；当前不是全游戏Boss池。跨房间Boss完整AI和新转友方战斗仍待实机确认。本轮按用户要求不进行测试，只编译打包，不宜直接当作已完成付费直播验收的正式版。
