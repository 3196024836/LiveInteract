# 0.5 使用说明

1. 完整解压包，运行“直播互动工具箱.exe”。
2. 正常退出旧工具与游戏，在“Mod与存档”安装/修复0.5，再通过Steam启动游戏。
3. 在规则页读取 profiles/丝之歌-弹幕助力.json，检查礼物名称/ID与实际直播间一致，再由本人开启互动。
4. OBS图片源选择“直播素材/丝之歌-友军整活”中的新版透明说明图。

全部免费/付费效果、永久随从的含义、随机Boss池与验收状态见 [0.5默认玩法说明](0.5默认玩法说明.md)。

小心心、啤酒、棒棒糖、热气球、跑车都要求正单价字段；零价或未知单价不会刷敌怪/Boss。其他正单价礼物有基础强友军助力兜底。配置改名后请同步修改直播图。

暂停与紧急恢复：Ctrl+Alt+F10暂停；Ctrl+Alt+F12紧急恢复（可在设置修改）。暂停保留未执行队列，紧急恢复会取消待执行并清理包括友军在内的本工具生成物。未知回执先查询，不盲目重发。重启积压需要明确恢复。

规则、登录态、队列与存档和程序包分开保存；不要把别人的用户数据目录覆盖自己的。维护和恢复存档前正常退出游戏，不删除其他Mod或未知加载器。

本轮没有启动游戏或执行测试，只有必要编译与打包。新阵营适配与Boss效果仍需实机验收，不能宣称实播100%触发。
