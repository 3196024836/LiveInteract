# 花花直播互动 0.8.7 · 远程小弟修复

## 更新方式
1. 正常退出旧版互动工具和游戏，完整解压本包，运行 `直播互动工具箱.exe`。
2. 点“一键准备游戏”更新游戏Mod，再从Steam启动《丝之歌》。仅换配置不能修复隔空掉血和索敌判定。
3. 点“使用内置方案”（已有规则先备份），或读取 `配置/丝之歌-弹幕助力.json`。
4. 想保留自定义规则时，只互换：**远程小弟=焦油螨，友方、1只、倍率1、持续0；远程小怪=朝圣钟卫，敌方、1只、倍率1、持续0**。

普通小弟仍是红色飞行机械随从，普通敌方小怪仍是颅潜虫；礼物、金币、回血、技能和点赞规则没有改变。`直播图`目录内为按本版配置重新输出的透明PNG。

## 修复后的行为
- 警戒/逃离范围不再隔空扣友军血。敌方身体、武器或弹体实际接触时，友军仍会受伤和死亡。
- 友军索敌只检测2D区域，不被精灵前后层级的Z差异干扰。
- 焦油弹按敌人身体中心校准出手方向；钟卫抛射按实际重力校准横向出手速度。仍是原作弹体和攻击节奏，不做离手追踪、瞬发命中或无敌。
- 友军与主播继续互不伤害；友军保留跨场景与传送跟随、离屏召回、绿色本体描边和召唤者名字。

移动目标可能躲开原作弹体，障碍物仍会挡住攻击；这不是必中或穿墙模式。本轮实际验收与尚未覆盖范围见 `0.8.7验收结果.md`。
