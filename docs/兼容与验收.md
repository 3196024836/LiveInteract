# 0.5 兼容与验收

目标仍为Windows x64、Steam丝之歌1.0.30000 / Build 22479045。新转友方功能适配四个原生单位的目标引用、阵营伤害、原生碰撞攻击和跟随，未换皮、未移植机械随从AI。新增原生预制体转阵营不等于游戏原版自带友军。

本轮按用户此前要求停止测试：只完成源码修改、必要编译与便携打包，不启动游戏、不跑自动测试。新增四种转友方的完整追敌/攻击/跟随、随机Boss的完整AI与真实付费直播都尚未完成实机验收。前序0.3/0.4的结果不能代替这些新功能的验收。

随机Boss池仅尼莱斯、针姬；每份触发1只，同一执行单位重试选择不变。Boss可能依赖原场景，仍标为试验。灵丝风暴是游戏原生施法动作，需要角色空闲；不是后台无动作伤害。

付费规则要求正单价。零价/单价未知只获得基础友军；这是为了不把免费/无法确认的输入误绑定敌怪或Boss，不代表识别出了它真实是否付费。价格变化、礼物改名或缺少字段需要主播通过接收记录核对。

原生敌人检测器可能只识别角色层，阵营适配会改写本实例状态机目标，并对本体刚体进行追敌/跟随引导；保持原生攻击状态机与当前启用的攻击碰撞，不给单位编造远程技能。具体原生行为兼容仍须实机确认。

个人账号、Cookie、原始直播帧、存档和本机测试资料不随发行公开。公开GitHub仍保留0.4发布，本轮没有自动发布0.5。
