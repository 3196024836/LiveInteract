# 兼容与验收状态

## 当前发布：0.4.0 预发布

当前包面向 Windows x64 与 Steam 丝之歌，游戏适配记录为1.0.30000 / Build 22479045。其他平台、其他游戏及后续游戏版本未据此确认兼容。

最终原生效果收敛版本只完成正式编译与打包；因交付要求停止测试，没有对该最终包再运行自动测试、游戏回归或长时间实播。原型阶段95项测试及部分原生随从攻击、跨场景跟随、体型独立计时检查属于前序候选的证据，不代表最终包全部功能已经验收。

## 实播仍需验证

- 抖音实际下发的弹幕、礼物、点赞与连击，需要在真实开播期间分别对照接收账本、执行队列和游戏回执。
- 本地持久化只能保留已收到的输入，不能恢复平台未下发或断网期间从未收到的事件。
- 发送命令、成功回执、数值实际变化、目标完整AI和观众实际消费记录是不同的证据；满值、等待和未知不能计为成功增量。
- 长时间直播、另一台没有开发环境的电脑，以及所有Boss跨房间的完整战斗流程仍未完成验收。

## 具体边界

Boss和部分场景效果依赖原关卡条件，保持试验用途；默认不绑定Boss或永久改档。六种原生丝技可能占用原生施法动作，默认配置关闭这些强制施放规则。体型整活是Mod提供的视觉叠层，不是游戏原版自带的玩法，不改变碰撞体。

原生机械随从使用原游戏外观与战斗AI；召唤、昵称、跨场景保留和直播规则是本Mod的交互逻辑，不代表游戏官方自带直播功能。

默认实体上限0为不限制，不等于无限硬件承载能力。大量实体与积压会增加性能开销；设置上限后超限单位等待，不静默丢弃。

已知本机加载器引导日志包含 Unable to start Unity log writer、Couldn't find a Game Manager / GameCameras；此前仍能进入游戏并连接，根因尚未确定。出现故障时以本次控制台的完整错误与具体动作状态判断，不将历史成功当作当前成功。
