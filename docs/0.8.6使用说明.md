# 花花直播互动 0.8.6 · 小弟跟随修复

## 更新后这样用
1. 正常退出旧版互动工具，完整解压本包，运行 `直播互动工具箱.exe`。
2. 游戏关闭时点击“一键准备游戏”，再从 Steam 启动游戏。必须更新 Mod，只有改配置不能修复状态机。
3. 点“使用内置方案”，载入本次两个小弟的新映射；已有规则会先备份。保留自己的规则时，只将“小弟”改为“原生机械友军”：1只、伤害参数8、持续0；将“远程小弟”改为“朝圣钟卫”：友方、1只、倍率1、持续0。
4. 连接本人直播间，确认直播和游戏连接后再开启互动。不要同时运行两份工具。

## 这版小弟的行为
- **小弟**：原作红色飞行机械随从，保留原生飞行、悬停与冲撞攻击。
- **远程小弟**：朝圣钟卫，使用它原有的行走、转身、跳跃和投掷攻击，不用自制弹体替代。
- 空闲地面随行：靠近至约2.5个游戏单位后待机；距离超过3.5再跟上，避免边界反复启停。走路播放原作Walk，到位播放Idle，朝向随实际移动方向。
- **同屏不会因距离远、跟随超时或暂停恢复而瞬移。**持续离开画面0.75秒后召回；过场结束已离屏时可直接召回。机械小弟自己的距离传送也受同屏限制。
- 有敌人时停止人工随行，攻击速度、投掷和跳跃交还原作状态机。有效敌人不会每0.25秒随意切换，死亡或越过追击范围才重新选目标。
- 友军和主播互不伤害；敌人仍可以伤害、杀死友军。召唤者名字和阵营本体描边保留。修正机械小弟描边遮住红色本体的问题。

此版不是重做全部怪物的AI：原作Boss、伏击、钻地、攀墙等特殊单位保留各自机制；完整名录的每一种战斗行为未在本轮逐只重测。

## 原有功能继续保留
- 默认仍为17条规则，敌方“小怪/远程小怪”、四件礼物、金币雨等没有改动。详见 `profiles/使用说明.md`；随包直播图按当前配置生成。
- 画面与设置：双方召唤总上限默认40只、生成间隔0.5秒、排队容量200次触发，可暂停补位。
- 默认F8清除本工具双方召唤物；快捷键可配置，游戏右下角显示。控制台尚未派发的余量由“紧急停止”取消。
- 本体友军绿边、敌军红边；描边独立开关，默认2像素，可调1～5像素；不改变原场景怪物。
- 精简包缺少.NET或WebView2时，在工具内部下载、校验、准备，不需要打开网页手动安装；首次准备需要联网。

实测证据与范围见 `0.8.6验收结果.md`。首次直播先保持召唤上限，别同时刷大量Boss。
