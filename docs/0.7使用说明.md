# 直播互动工具箱0.7 使用说明

## 开始使用

1. 完整解压，双击“直播互动工具箱.exe”。不要只复制EXE，payload和profiles需要保留。
2. 正常退出游戏，在“Mod与存档”安装/修复0.7，再通过Steam启动游戏。
3. 点“使用内置方案”，再到“礼物绑定”核对礼物名称/实际ID。现有规则先备份，不会静默覆盖。
4. 点“连接直播间”，在内置窗口选择平台，由本人登录和验证，确认收包、游戏连接后手动开启互动。
5. OBS添加“图片”源，选择“直播图/直播互动说明-透明.png”。

## 直播平台

同时支持抖音与哔哩哔哩，两个平台共用同一套规则、账本、队列和校验：

- 抖音：填直播间短号或 live.douyin.com 地址。
- 哔哩哔哩：填直播间号或 live.bilibili.com 地址。

窗口只观察网页自己已经收到的弹幕长连接数据，不代替你登录、不发送平台消息。哔哩哔哩解析弹幕、礼物、点赞总量、进场/关注/分享和醒目留言；礼物单价取平台给出的金瓜子（1000金瓜子＝1元），与抖音的“钻”不是同一单位，跨平台请用礼物名称匹配，不要用单价区间。

礼物名称两个平台不同：默认配置里是抖音的四个礼物，换到哔哩哔哩要在“礼物绑定”里从收到的记录重新选择实际名称，不能沿用旧名字。

## 默认配置

弹幕、点赞和礼物的准确数量见 profiles/使用说明.md。本包已按最后确认改成：金币弹幕原生金币雨；回血/回蓝各1；点赞只保留每100赞金币雨；四礼物每1份独立触发，无累计门槛。

如实际直播间“给到夯”等名称不同，打开“礼物绑定”从收到的记录选择实际名称，或填写网页事件里的真实ID。不要把开放平台加密sec_gift_id当作网页数据的原始gift_id。绑定修改后要同步直播图。

暂停：Ctrl+Alt+F10；紧急停止/恢复：Ctrl+Alt+F12（均可在设置修改）。暂停保留队列；紧急恢复取消余量并清理本工具对象。未知回执先查询，不盲目重发。旧积压由主播明确选择恢复。

## 友军行为

原生友军会被敌人打伤：贴身攻击、接触碰撞和Boss范围攻击都按原伤害结算，血量归零就按原作死亡。主播的针、道具和其他友军不会误伤自己的小弟。

切换场景、传送、重生都重新归位到角色身侧；追不上超过两秒也会直接归位。角色死亡不再让友军消失，也不会把友军留在旧场景或长椅上。友军死亡只清理它自己，不影响其他友军和主播。

回血在满血时不会浪费：溢出的部分变成临时额外血量上限，每次刷新30秒、最多叠到＋5，切场景、死亡和紧急停止都会收回，控制台“剩余效果”里能看到剩余秒数。

同一套插件只能有一个副本：只放在 BepInEx/plugins/LiveInteract/，不要在 plugins 根目录再放一份，否则会出现两个插件实例重复加载。

## 单位上限与排队

设置里的“本工具生成敌人同时存在上限”达到后，新单位不再报错，而是进入队列等待：场上有单位被击败，就按先进先出自动补生成，礼物不会丢。

排队期间游戏内左下角会一直显示“谁 · 效果 · 待生成”，补生成成功时再显示一行提示；紧急停止会清空队列。上限只统计本工具生成的敌对单位，常驻友军不计入，0 表示不设上限。

## 为什么这个包小

精简包复用系统 .NET 10 Windows Desktop Runtime 和 Microsoft Edge WebView2 Runtime，不再重复携带大体积固定浏览器与.NET环境。本机已确认有.NET桌面10.0.12及WebView2 155.0.4283.62。换电脑如果缺组件，按启动提示安装 .NET 10 Desktop Runtime；直播间窗口会给出安装微软WebView2的按钮。内置浏览器版则自带固定 WebView2（WebView2Runtime 目录）。

软件只带主程序、Mod/加载器载荷、默认配置、直播图和必需第三方许可。不包含游戏本体/程序集、登录态、存档、原始帧或测试数据。

## 直播图来源

四件礼物使用抖音直播间官方礼物列表返回的原图：小心心（463）、玫瑰（2001）、棒棒糖（165）、给到夯（16075），图上不标未经核实的金额。图标文件在 直播素材/官方礼物图标/，来源与单价记录在同目录 sources.json；平台换图后替换同名文件重新生成即可。

## 当前验收状态

本轮只做必要编译、打包与静态自检，没有启动游戏或运行自动测试。原生转友方（尤其远程/Boss）、金币雨、5秒召唤及实播礼物仍待实机验证，不能宣称100%生效或100%读到平台未下发的数据。先核对接收账本、队列、错误日志和游戏回执，再用于付费直播。

0.6.1 的友军承伤/跨场景归位/死亡后保留、0.6.2 的排队补生成、0.7 的哔哩哔哩接入同样只经过编译和构造数据的解析自检，实机与真实直播间表现需要主播跑一轮确认。

旧版本包保留，GitHub公开版没有自动更新。本包不自动覆盖真实用户规则、存档或当前运行的游戏。
