# 快速开始

## 下载安装

1. 从 GitHub 的 v0.4.0 发布页下载 Windows x64 ZIP，完整解压到一个固定文件夹。
2. 双击“直播互动工具箱.exe”。不要只复制 EXE，旁边的运行环境和 payload 文件夹需要一起保留。
3. 在“Mod 与存档”中选择 Steam 丝之歌安装目录，执行安装 / 修复。维护前工具会备份存档，游戏运行中不能替换已加载 DLL。
4. 正常通过 Steam 启动游戏，等待工具显示游戏已连接，再进入角色场景。

不需要自己安装 .NET SDK 或 WebView2。开发者从源码构建时才需要 SDK 和本机游戏引用。

## 连接自己的抖音直播

在工具内打开抖音接入页面，由本人完成登录及平台要求的验证，进入自己的直播间。先确认开播状态和真实收到的互动，再开启派发；不要把网页能够打开当成已经收到弹幕或礼物。

程序不绕过验证码或账号风控，不代替平台补造未下发的数据。不要向他人分享内置浏览器的数据目录。

## 读取默认规则

在“触发规则”中点“读取默认助力配置”，选择包内 profiles/丝之歌-弹幕助力.json。工具先备份旧规则；导入不会自动开启互动。

默认配置包含20条启用规则、10条停用的备用规则。小心心、玫瑰与礼物档位召唤原生机械随从；回血和回丝使用游戏已有入口。完整别名、数量、档位见 profiles/使用说明.md。

数量、持续时间和礼物单价上下限可以在规则编辑器改动。分档使用平台实际单价字段，不把礼物连击总数量当单价。按规则顺序优先匹配：具名礼物在前，通用单价档位在后。

## 主播的控制与核对

- 暂停：暂停新触发与派发，保留未完成队列；已经发往游戏的操作不强行撤回。
- 紧急停止 / 恢复：取消待执行效果，恢复临时效果并清理本工具生成物，包括随从。
- 默认快捷键：Ctrl + Alt + F10 暂停；Ctrl + Alt + F12 紧急恢复，可在设置中修改。
- 查看“收到的输入 / 执行队列 / 运行日志”，按昵称、来源、状态、效果和原因筛选。
- 结果未知时先“核对选中的未知回执”，不要直接重新赠送或盲目重发。重启积压队列需要本人明确恢复。
- 满血 / 满丝显示无变化；过场、死亡、目标暂时不存在和实体上限等条件会留队等待。

付费直播前请用自己的测试直播分别核对弹幕、礼物单份、连续赠送和点赞门槛。当前版本的真实付费事件完整率未验收。

## 加入直播画面

- 游戏内：仅触发时显示昵称、效果与数量 / 倍率，通知向上排列并渐隐；召唤物头顶显示昵称。
- OBS 动态通知：添加“浏览器”源，使用工具设置页给出的本机地址；显示服务不提供游戏控制接口。
- 静态玩法说明：添加“图片”源，选择直播素材/丝之歌-友军整活 下的横版或竖版透明 PNG。修改规则后要同步修改说明图。

## 升级或停用

正常退出游戏和旧工具后，解压新包并在 Mod 管理中安装 / 修复新版本。用户规则和登录态与程序分开保存，不要用别人的用户数据目录覆盖自己的目录。

停用 / 卸载使用工具自身入口，不删除其他 Mod 或未知加载器。恢复存档前正常退出游戏；恢复会先保留当前存档为新恢复点，Steam 云同步可能影响最终存档状态。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 游戏未连接 | 核对所选目录、Mod 启用状态和版本；退出游戏后安装 / 修复，再通过 Steam 启动 |
| 已连接但不能触发 | 进入可操作角色场景，查看队列中具体等待条件 |
| 生成物没有目标 / 目标缺失 | 进入有对应敌人的场景；等待资源加载；不要把 Boss 在其他房间的 AI 当作已兼容 |
| 礼物没有出现 | 先找接收账本中的礼物记录，再查匹配规则、队列与游戏回执 |
| 游戏卡顿 / 队列积压 | 默认实体上限0为不限制；按实际机器承载能力设置上限或暂停，查看积压原因 |
| 平台要求登录或验证 | 本人完成验证，不绕过平台安全措施 |

问题反馈请附版本、操作步骤和去除个人信息的错误原文，不上传登录数据或个人存档。
