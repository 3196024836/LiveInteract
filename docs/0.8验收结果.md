# 0.8 预览修复版：验收结果

## 这份包可以核对什么

本版修复友军误伤并统一阵营配置。**全怪物完整验收尚未通过，因此按预览版交付，不作为“全功能全部正常”的稳定版。**

- 规则里，同一种怪物只保留一个条目，选择友方/敌方，再配置数量、强度和存在时间。场景生成、随机生成和复制也有阵营选项。
- 旧规则仍能读取。编辑时在副本上转换，取消不改变原规则；未覆盖用户当前配置。
- 默认方案和透明直播图保留在包内。默认随机池继续使用原有的26种单位，不把仍有故障的扩展单位放入付费礼物随机池；这不是234种全目录随机。
- 游戏测试使用独立档位副本。精简包不附带游戏程序集、游戏资源、本机缓存、登录态或测试存档。

## 已修复并复现过的原因

1. 原作远程攻击有一条反射调用的快速伤害入口，会绕过普通受伤方法。现在补齐伤害、目标和弹体归属保护。
2. 发射者死亡后，仍存活的独立弹体协程曾被提前取消，影响原生回收；现在按实际执行对象管理寿命，并保留友方身份，不回退成追踪主播。
3. 部分原作机关每轮攻击都会自动回满血。带新增生命组件的召唤副本已禁止这项自动回满，普通攻击的伤害现在能保留。
4. 一个复合单位曾只映射到头部受击节点。已改为完整原作本体，生命部件死亡后清理整个召唤单位。
5. 复制本工具已生成的单位时曾重复复制所有权标记。现在只保留一个标记，保留原怪物身份和完整本体。
6. 场景资源提取已补齐原作预加载引用和依赖，不再用空资源或其他怪物替代。仍有部分单位依赖原房间的控制器，见待修清单。

## 逐只召唤的范围与未完成项

本轮目录234项，累计覆盖友方/敌方468组召唤尝试。最近一份适用记录中，439组通过当前基础用例，29组尚未通过。基础用例检查生成、阵营、承伤、死亡、友军不伤害主播，以及友军是否出现有效攻击；**敌方逐只主动攻击、Boss完整招式和所有跨房间阶段仍未完成验证**。

记录来自本轮多个候选构建，采用同一对象最近的适用结果；不是宣称同一个发行二进制完成了468组全功能测试。每项的原始记录文件名见同目录《0.8召唤验收.csv》，完整记录保存在项目 artifacts/audit-0.8。

已记录的友军伤害对照没有出现主播扣血。仍未独立映射的三项原作图鉴内容为 Maggots、Wisp、Void Tendrils，不用替代怪冒充。

## 使用与回退

1. 正常退出游戏，完整解压本包，运行“直播互动工具箱.exe”。
2. 在“Mod与存档”安装/修复0.8；不要只替换EXE，也不要把Mod DLL重复放到plugins根目录。
3. 保留自己的规则；需要时手动读取profiles里的默认方案。扩展待修单位暂不要绑定到付费礼物。
4. OBS图片源使用“直播图/直播互动说明-透明.png”。
5. 出错看内置控制台和队列状态。未知回执先查询，不要直接重发；紧急停止会取消未执行余量并清理本工具对象。

上一版包和安装前DLL已保留。本次不自动发布或推送GitHub。
