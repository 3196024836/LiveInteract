# 0.9.1 更新说明

召唤池、默认18条规则和礼物设置与0.9.0相同，直接覆盖更新即可；需要同时更新游戏内Mod（软件里点“一键准备游戏”）。

## 修复

- **被敌方召唤物打死后无法复活**：以前主播被敌方召唤物打死，会一直停在死亡状态。现在会正常复活（实测约7秒）。
- **友军目标消失后的报错**：友军正在追打的敌人被击杀或清场后，原作的追击、转身动作会读到已经消失的目标并在日志里刷错。现在改为指向友军当前的有效目标。
- 召唤Boss死亡时的慢镜头拦截不再报 `routine is null`；清场当帧刚生成的友军被销毁时不再报空引用。

## 性能

- 召唤物多时的周期性卡顿（每秒约4次、每次10～17毫秒）已消除。
- 满屏40只单位时，帧率从个位数提升到约18～41（同一台机器、同一组随机召唤对比）。
- 20友军＋12敌军满载对比0.9.0，平均帧率提升约3%～27%（视单位组合而定）。帧数主要仍由原作怪物逻辑决定。

## 验证

- 4只友军（颅潜虫、燧石飞工、狱卒蝇、木蜂）31项核心矩阵全部通过，与0.9.0一致。
- 15分钟与6分钟模拟直播长测跑完，日志空引用为0，内存随回收正常回落。
- 825项自动测试通过。
