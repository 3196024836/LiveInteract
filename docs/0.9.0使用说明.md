# 花花直播互动 0.9.0 · 稳定召唤版

## 开始使用

1. 正常退出旧工具和游戏；备份自己的规则，将本包完整解压到独立目录。
2. 运行 `直播互动工具箱.exe`，点“一键准备游戏”安装本版Mod，再从Steam启动游戏。精简包沿用工具的私有.NET/WebView2准备流程。
3. 要采用本版18条默认规则，点“使用内置方案”。已有自定义配置不会自动替换，旧方案请先备份。
4. 核对规则后再开互动总开关。复制礼物可用本地测试输入验证，不需要付费直播测试。

本版当前可生成池的6种怪物及原作机械小弟，逐只友军功能已经通过。234项是分类档案，不是234项全部开放。10项明确排除（含当前适配失败），218项尚未完成逐只验收而关闭；关闭待验不等于确认不适合，全目录筛选仍未完成。当前无开放Boss，强力池只含已通过的强怪狱卒蝇。

### 复制礼物如何等待

- 没有合适敌人时，任务一直保留，不超时、不算成功；等下一只同屏存活、属于稳定白名单的敌人出现。
- 复制同一种类的全新1×友军，不夺走原敌人，不复制敌人的受伤或剧情状态。首次选中后，资源加载和容量排队不改变已选种类。
- 带绿色本体描边，头顶显示实际送礼者名字；名字允许重叠，只跟随自己的身体，不再相互推挤。
- “永久”表示没有存续倒计时；仍可正常受伤、死亡、被清场，正常切场景继续跟随，不写入正式存档。退出游戏不会把已经生成的召唤物保存为永久存档单位。
- 尚未遇敌的任务使用原有持久队列；工具重启后待主播明确恢复。清场/紧急停止按既有撤回规则处理。
- 固定地形怪、场景机关、无攻击单位及未开放Boss不会借复制入口放行。

## 可用名单与友军行为

弱怪5种：颅潜虫、焦油螨、燧石飞工、木蜂、壳木蚋虫（枯木蚊）。强怪1种：狱卒蝇，使用地面行走随行。机械小弟独立保留，不进入怪物随机池。

无敌人时跟随，近处停止、远处接近；地面走路、飞行正常飞行。同屏不按距离瞬移，持续离屏才召回。发现有效敌人时主动使用原作攻击，不需要主播先出手；主播真正命中另一敌人后优先集火，目标死亡/失效后换敌或恢复随行。友军自身攻击不刷新主播点名。

友军可被真实敌方攻击伤害和击杀；主播与其他友军互不误伤。警戒框、零伤害触发器不扣血。投射物仍可被地形挡住，移动敌人可以躲开，不是必中或穿墙模式。原生机械小弟保留其原作随行范围和轻微盘旋。

描边与身体保持相同排序层、顺序和渲染队列，仅略放在本体后方；不会因降低渲染队列掉到背景层，也不把整个身体染成纯色。

## 分类与旧配置

保留弱怪121、强怪78、Boss35，共234项分类。分类与召唤资格独立。新 `weak` 只抽弱怪，`strongBoss` 只抽强怪和Boss，单位等概率，不给Boss额外权重；当前强力池只有狱卒蝇。

旧 `ordinary` 保留非Boss含义，`all` 保留全档位含义，仍额外检查旧 `RandomEligible`；界面明确标“旧版”，不会静默改写自定义规则或倍率。已有旧规则未写pool仍按ordinary。新弱怪池包含焦油螨和码头飞工，旧随机限制不因此改变。

无攻击、明确排除、未批准、未知准确名、空池均明确拒绝，不生成替代怪，也不退回机械小弟。滑叶虫与生质飞籽原作无攻击，不补攻击能力。

## 清理与回退

F8调用召唤清场，只清本工具召唤物、派生攻击和游戏端待生成；不重置其他增益或原场景生物。快捷键可在设置中启用/修改。双方默认总上限40、生成间隔0.5秒，超量逐只排队，实际完成后才算成功。

回退前关闭互动、正常退出游戏和工具，从保留的旧版目录启动并重新安装旧版Mod、恢复对应规则备份。不要混用新旧Mod。测试使用独立profile4，不操作正式存档。本包不包含QA入口、游戏程序集、游戏资源或存档，不自动发布GitHub。

本包附分类、234项筛选及7种友军逐只验收CSV、验收说明与按18条规则生成的透明直播图。原始实机记录位于本地项目 `artifacts/ally-ai-0.9.0/final/`。
