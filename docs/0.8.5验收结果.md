# 花花直播互动 0.8.5 本体描边测试记录

## 实现范围
召唤物本体轮廓：友军绿色#63F58D，敌军红色#FF5261，默认2像素。软件可独立开关及调1～5像素；与名字和触发队列开关独立。普通、具名、随机、强力、Boss与机械随从共用召唤挂接入口，复制前移除旧辅助轮廓，不叠加攻击/碰撞/生命组件。

只读取原作帧网格、UV、透明度及材质排序，在本体后绘制独立轮廓，不染原模型，不修改原作共享材质。沿用本机原作透明Shader，不携带或分发游戏贴图/Shader资源。多方向合并为每个原渲染器一个辅助渲染器，关闭、离屏、清场和销毁时停止或释放；不可读静态网格为几何扩边兼容。

- 204项自动化单元/集成测试通过。含阵营轮廓颜色、八方向采样、像素粗细范围；既有召唤排队、账本、配置和更新测试保留。
- 实际WPF：关闭名字/队列同时开启本体描边，3.5像素设置保存与同步载荷一致；有效状态显示使用隔离夹具，不冒充游戏运行截图。既有F8录键、队列字段与暂停设置检查仍通过。
- 本机原作shaders_assets_all.bundle只读检查确认Sprites/Default-ColorFlash具有透明纹理、闪光颜色和闪光量属性；ZWrite关闭、双面、透明混合。源记录outline-native-shader.json。
- 正式非QA构建和包内检查见本轮打包日志；QA专用视觉夹具与探针不进入用户包。
