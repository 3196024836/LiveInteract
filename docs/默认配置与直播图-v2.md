# 0.4.0 预发布说明

快速安装和接入见 [快速开始](快速开始.md)；功能与改动见 [版本记录](../CHANGELOG.md)；默认口令与礼物规则见 [配置说明](../profiles/使用说明.md)。

本版本以原生效果为主：游戏原生机械飞行随从、回血、回丝，以及明确标注的Mod体型整活和普通敌人复制。没有自制补给球、换皮新友军或AI绘制的游戏美术。

随从显示召唤者并跨房间跟随；恢复整活不会清理随从，紧急停止会清理。默认20条启用、10条备用停用规则，需要本人从JSON读取并手动开启互动。

最终原生效果调整完成编译打包，未重新测试，真实付费直播仍需验收。完整边界见 [兼容与验收](兼容与验收.md)。
