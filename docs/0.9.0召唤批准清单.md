## 生产统一检查

- `SummonEligibility.RejectionReason(MonsterDefinition monster)`：允许时空串，否则返回具体中文原因。
- `SummonEligibility.Require(MonsterDefinition monster)`：拒绝时抛`ArgumentException`。
- `SummonCommands.Resolve(string name)`：准确名/别名/ID/资源路径解析后强制检查，不生成替代单位。
- `NativeSummons.Convert`、四个随机池、Boss池、旧免费友军池全部检查。空池抛`InvalidOperationException`，不回退。
- `ActionValidation.Validate`检查直接spawn、旧native/convert、准确名与资源入口。无法确认批准来源的旧场景复制入口直接拒绝。运行时从场景解析出来源后，生成之前仍须调用`Require`，不能靠找到资源就放行。
- 四池分档保留：weak=弱怪；strongBoss=强怪和Boss；ordinary=非Boss；all=全部。新 `weak`/`strongBoss` 仅按 `CanFight + SummonEligible + Tier` 选取；旧 `ordinary`/`all`、bool重载及 `Boss`/`FreeAlly` 仍额外要求 `RandomEligible`。该字段仅保留历史随机限制，归档false标记不改；焦油螨与码头飞工进入新弱怪池，不进入旧池。 bool重载false/true仍分别对应ordinary/all。

机械小弟`ally.clockwork`不受怪物门控影响。
