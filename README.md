# 花花直播互动 · 0.9.1

Windows本地直播互动工具，支持抖音与哔哩哔哩，首个适配游戏为《空洞骑士：丝之歌》。

当前友方召唤池81种（弱怪56、强怪22、Boss 3）＋独立原作机械小弟，逐只31项核心矩阵实机通过；敌方召唤池172种（弱怪97、强怪57、Boss 18），逐只6项敌方筛测通过，其中4种只开放友方、95种只开放敌方。234项保留为分类档案：11项永久排除（固定地形/原作无攻击等），其余未入池单位标“待修”关闭，不删除。逐只结论见 `docs/0.9.0召唤池结论.csv`。新普通池只抽弱怪，强力池只抽强怪＋Boss。

名字允许重叠，跟随身体，不再相互推挤；本体描边修正背景排序。新增“大啤酒”礼物（按准确名称匹配，不依赖单价字段），每份永久复制下一只合适敌人为友军，显示送礼者名字；无目标保留，无TTL但正常受伤死亡。
