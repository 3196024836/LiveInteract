# 丝之歌 · 原生援军与轻整活（0.4）

在新版“触发规则”中点“读取默认助力配置”，选择本目录的 `丝之歌-弹幕助力.json`。旧规则先备份，互动开关不会自动打开。不要用0.3程序读取本文件。

## 弹幕

- 回血 / 加血 / 奶我 / 救命：调用游戏回血入口，+2格。满血会显示无变化。
- 回丝 / 回蓝 / 能量：补充原生灵丝6点。满丝会显示无变化。
- 小弟 / 援军 / 帮忙：召唤游戏原生机械飞行随从1只，12秒。
- 怪变大 / 巨兽登场、怪变小 / 迷你怪：目标敌人外观每条叠一层、各8秒独立计时；不扩大碰撞、不改主播操作。
- 复制 / 影分身：复制最近普通敌人1只，排除Boss。
- 小怪 / 刷怪：生成颅潜虫1只。
- 清场 / 清怪 / 清理：只清本工具敌对召唤，保留随从。
- 恢复 / 恢复正常 / 重置 / 救场：恢复体型整活并清敌对召唤，保留随从。
- 每5条未命中口令的普通聊天回血1格；每50赞补充3点灵丝，余数累计；关注回血1格。

## 礼物

名称规则优先：小心心→原生机械随从1只；玫瑰→2只；棒棒糖→敌对木蜂1只；啤酒→复制普通敌人1只。

其他礼物按平台字段给出的单价分档：低于10钻或单价未知→1只；10–99钻→2只；100–499钻→3只；500钻及以上→4只。全部使用原生机械随从，不伪造新种类。每份礼物独立计数，连续赠送不替换前一只；礼物随从不自动计时离场，跨房间跟随，头顶显示召唤者名字。退出游戏、紧急停止会清理。

默认不限制同时生成数量；大量同时存在仍会增加游戏负载，可在设置中显式设置上限，超限单位留队等待。变大/变小每层保留自己的触发者和到期时间，多次触发不刷新覆盖前一条。

大招、数值增益、额外无敌和自制护盾默认停用。原生丝技仍可从功能库选择，但可能占用角色短暂施法动作；默认不接管操作。

本包没有自制补给球、没有换皮友军、没有AI绘制素材。透明直播图为纯文字规则说明，可作为OBS图片源叠加。规则变化后需要重新生成或修改说明图。
