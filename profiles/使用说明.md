# 花花直播互动 · 默认玩法

在软件点“使用内置方案”即可；已有规则先备份，互动总开关保持关闭。也可读取同目录JSON。

**0.9.0稳定召唤版：开放池6种怪物及机械小弟逐只友军功能已通过。** 其余228项关闭（10项明确排除（含当前适配失败）、218项尚未完成验收；不是234项已全部筛测）。远程小弟为码头飞工、远程小怪为焦油螨、小怪为颅潜虫；机械小弟保留原生AI。

原生友军会被敌人打伤，主播和其他友军不会误伤；切换场景、传送、重生后保留；离开画面后召回角色身侧，角色死亡不会让友军消失。

在“画面与设置 → 召唤排队与性能保护”设置双方总上限、敌方额外上限、生成间隔、排队容量和暂停补位。双方默认合计40只、间隔0.5秒、容量200次触发；本方案旧SpawnLimitOverride=0只表示不额外限敌军，不会关闭总上限。超量逐只排队补位，游戏左下角显示触发者与剩余数量，软件显示场上及待生成数量；排队尚未完成不会计为成功。

弹幕基础召唤：小弟→原作红色飞行机械小弟1只（保留原生飞行与攻击）；远程小弟→友方码头飞工1只（1×原作数值）；小怪→敌方颅潜虫1只；远程小怪→敌方焦油螨1只。友方持续跟随、无倒计时；敌方保持敌对。其他弹幕：生成怪物＋准确名称/生成小弟＋准确名称→对应阵营1只、5秒后消失；怪变大/怪变小→最近敌人永久外观叠层（不改碰撞）；回血→1格，满血时改为临时额外血量上限＋1（每次刷新30秒，最多＋5，切场景/死亡/紧急停止收回）；回蓝/回丝→1点；金币→10颗原作可拾取念珠；技能→苍白之爪。

点赞仅保留：每100赞→120颗超大原生念珠雨。没有20赞回血、50赞回蓝等旧点赞规则。

每1份小心心→2只独立随机弱怪友军；每1朵玫瑰→1只随机弱怪敌人；每1份棒棒糖→2只随机强怪/Boss友军；每1份给到夯→1只随机强怪/Boss敌人。四件礼物均为原作1×强度，不额外放大生命或伤害。没有按5/10份累计的门槛，也不依赖价格字段才能命中。组合赠送按归一化后的整数新增份数派发。

常驻友军显示召唤者，随传送/切场景保留；精准召唤5秒计时在过场暂停。退出游戏或主播紧急恢复清理常驻友军。没有2元挑战，没有默认复制弹幕口令。新增礼物“大啤酒”（按准确名称匹配，不依赖单价字段），每份永久复制下一只同屏合适敌人为友军；无目标保留，名字为送礼者，绿色描边。无TTL但可正常受伤/死亡，不写档。

精准名称以“游戏功能库”名录为准，例如“生成怪物 木蜂”“生成小弟 燧石飞工”。不认识名称会报错，不生成其他单位代替。随机池是本版本适配名录，不是全游戏任意怪物文件。新方案使用弱怪池与强怪 + Boss池，两池不交叉。新 `weak`/`strongBoss` 仅按 `CanFight + SummonEligible + Tier` 选取；旧 `ordinary`/`all`、bool重载及 `Boss`/`FreeAlly` 仍额外要求 `RandomEligible`。该字段仅保留历史随机限制，归档false标记不改；焦油螨与码头飞工进入新弱怪池，不进入旧池。 新弱怪池含五项，强怪/Boss池仅狱卒蝇；空池明确报错，不回退。旧规则的普通池（ordinary）仍包含弱怪与强怪、不含Boss；全池（all）仍包含全部可随机战斗单位，界面标为“旧版”。已有自定义规则和倍率不会自动改写。滑叶虫与生质飞籽原作没有攻击，不在可选目录中；旧具名调用明确报错，不换成其他怪。

金币雨只生成原生拾取物，不直接加钱，触碰后由原作入账；资源尚未加载会明确等待。新默认方案不增强生命/伤害；已有规则手动配置的倍率按原值保留。普通小弟使用原作机械随从；具名及随机友军使用对应原生怪物转阵营，不替换成机械随从。

本方案为18条规则。0.9.0按本轮实测确定远程小弟为码头飞工、远程小怪为焦油螨，替换旧版焦油螨/朝圣钟卫组合；保留原规则ID、触发、数量、阵营和1×倍率，四件礼物使用新分档池。钟卫双向随行视觉反向，不做专属硬适配，本轮不批准。只认真实敌方伤害碰撞，不把警戒范围当成攻击；友军视野按2D检测，不受精灵Z排序影响。旧版焦油螨与钟卫的出手校准记录只作历史资料，不代替当前候选的完整验收；保留原作弹体、重力、反弹和攻击节奏，不追加追踪弹或必中特效。同屏不因距离瞬移，离屏持续0.75秒后召回。0.8.7实测范围见对应验收结果；0.9.0分类属于目录配置，主动战斗与随行以本轮独立运行时验收为准。
